## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, report them privately via
[GitHub Security Advisories](https://github.com/aaheiev/aaheiev/security/advisories/new)
or by contacting the maintainer directly.

You can expect an initial response within a few business days. Please include:

- A description of the vulnerability
- Steps to reproduce
- Any potential impact you are aware of
